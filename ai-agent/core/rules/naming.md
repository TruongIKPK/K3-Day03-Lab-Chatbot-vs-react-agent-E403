# 🏷️ QUY TẮC ĐẶT TÊN (NAMING CONVENTIONS)

1. Tên hàm Tool: Dùng snake_case (VD: `get_order_details`, `check_return_eligibility`).
2. Tên biến Prompt: Dùng UPPER_SNAKE_CASE (VD: `REACT_SYSTEM_PROMPT`, `CHATBOT_BASELINE_PROMPT`).
3. Mã đơn hàng (order_code): Định dạng `ORD-XXXX` (VD: `ORD-8899`).
4. Mã vận đơn (tracking_number): Định dạng `[CARRIER]XXXXXX` (VD: `GHN123456789`).
